# One Line, One Laugh — The Printer That Reads

Entry for [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) on make.fun: one joke, one line, about an ordinary office machine with a suspicious inner life.

`main.ts` (Node 22, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), checks it against the competition gate — UTF-8, 1–140 characters, a single line, no leading or trailing whitespace — and then reads the file back to verify it matches byte for byte.

## The joke

> My printer only jams on important documents, which is how I know it can read.

77 characters, one line, deterministic: every run produces byte-identical output.

## Why it works

The joke lands on the printer's timing. It never jams on a test page or a coupon — only on the document that matters. The only explanation left is that it knows which one that is, and it chooses to jam anyway.

## Run

```sh
node main.ts
```
